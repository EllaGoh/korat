states: "THIS IS NOT VALID YET! CURRENTLY CODE IS UNDER MIT LICENSE".
The Apache License 2.0 text that follows is therefore not presented here
as the effective license for Alloy. The matching Alloy 6.2.0 visualizer
source also carries an MIT notice, with a historical "Alloy Analyzer 4"
header. That header does not identify the running library version.
Source: https://github.com/AlloyTools/org.alloytools.alloy/blob/794226dd07b536fe35c5ca44b529417183cd629b/org.alloytools.alloy.application/src/main/java/edu/mit/csail/sdg/alloy4viz/VizGUI.java

Only org.alloytools.alloy-LICENSE.txt is included as a separate license
file for the active Alloy distribution. Embedded third-party licenses
and notices remain inside the unmodified Alloy JAR; they are not extracted
into separate files. This inventory does not assign one license to every
component bundled in that JAR.
